# otter
A Bittorrent client built in C#.

# about
Otter is a Bittorrent client built in C#. It is a CLI tool and displays info about your .torrent and the SHA1 hash.
#
It allows you to check out other peers on the Bittorrent network.
#
This is very very far from finished but if you want, you can check it out or maybe contribute!
#
Unix recommended.
#
Have fun! :)
